# Информер «PRTV RSS»

«PRTV RSS» показывает на слайде свежие записи сайтов из их RSS- или Atom-лент: новости города, отрасли, спорта, блога заведения. Хозяину ничего не нужно обновлять — сайт публикует, экран показывает. Информер выделен из «Ленты» (prtv-feed-widget) и умеет только RSS; Google Таблица, Календарь и Новости — в информере «PRTV Google» (prtv-informer-google).

Конструктор (v1.0.0): **https://s.prtv.su/wp-content/plugins/prtv-informer-feed/index_in.php** — слева настройки, справа живой предпросмотр в четырёх размерах (16:9 · 1920×1080, 9:16 · 1080×1920, блок · 600×300, полоса · 1920×200). Кнопки «Сохранить» нет: код пересобирается при каждом изменении.

## 1. Как поставить на слайд

1. Настроить информер в конструкторе.
2. Внизу справа, «Код для вставки — блок «HTML» на слайде» → **«Скопировать код»**. Это `<iframe>` 100%×100%: он займёт весь HTML-блок.
3. В редакторе prtv.pro: левая панель → **HTML** → вставить код в поле «Код HTML». Размер и положение задаются на слайде (prtv-element-layout).
4. Если информер лежит на фото или цветном фоне — в панели элемента выставить альфу фона блока в 0 (prtv-widgets §5).
5. Проверить в предпросмотре слайд-шоу и на ТВ.

Изменить готовый информер: «Продолжить настройку готового информера» → вставить ссылку или код iframe (подходят и ссылки старой «Ленты» с RSS-источниками) → «Загрузить настройки». Потом скопировать новый код и заменить HTML блока.

## 2. Источники — блок «Ленты»

- **«+ Добавить ленту (до 5)».** В поле — адрес RSS- или Atom-ленты; обычно это `/rss`, `/feed` или `/rss.xml` сайта. Кнопка **«Проверить»** показывает, читается ли лента, сколько в ней записей и сколько с картинкой.
- **Адрес страницы вместо ленты.** Можно вставить адрес самого сайта — информер поищет ленту по ссылке на странице. Найденная лента может оказаться общей лентой сайта, а не нужной рубрики: смотреть название в результате «Проверить». Если на странице ленты нет, проверка так и скажет — искать значок RSS или пробовать `/rss`, `/feed`.
- **Подпись на экране.** У каждой ленты поле «Подпись на экране (пусто — название ленты)». Длинные названия изданий («Новости — Футбол, хоккей, баскетбол…») заменять короткими: «Sports.ru», «Наука». В ссылке подпись пишется через тильду: `адрес~Подпись`.
- **«Несколько лент на экране»:** **«Чередовать: по записи из каждой ленты»** (умолчание) — каждый сайт представлен на экране, частая лента не вытесняет редкую; **«Поровну из каждой ленты, общий порядок по дате»** — та же доля на ленту, но показ по времени публикации. Одна и та же новость из двух лент показывается один раз.
- Перед публикацией проверить каждую ленту: часть известных адресов отвечает 404, 403 или не успевает ответить, у части лент нет картинок.

## 3. Отбор записей

| Поле | Что делает |
|---|---|
| Записей | Сколько записей в показе (1–50, по умолчанию 10) |
| Не старше, ч | Отсечь старые записи; 0 — без ограничения |
| Мин. длина текста | Убрать записи-заглушки без текста; 0 — без ограничения |
| Только со словами | Показывать только записи с этими словами |
| Исключить слова | Скрыть записи с этими словами |
| Только новости с картинкой | Для режимов, где фото — главное |
| Порядок | Сначала новые / Сначала старые |

**Как работает фильтр слов.** Слова через запятую; ищутся **целые слова** (или фразы) в заголовке, тексте и рубрике; регистр и «е/ё» не различаются. Словоформы фильтр не понимает: «кофе» не совпадёт с «кофейня», «Москва» — с «Москве». Поэтому формы перечислять: `Москва, Москвы, Москве, Москву, Москвой, московский, московская, московские, москвичи`. Проверено на трёх общих лентах: одно слово дало 2 записи из 50, перечень форм — 23.

**Исключения — не цензура.** В общих лентах политика и происшествия проходят под сотнями разных слов. Для детских учреждений и клиник брать тематические ленты (кулинария, наука, путешествия, спорт), а не общие новости; исключения — второй рубеж.

## 4. Режимы показа — «Режим показа → Тип»

| Тип | Что на экране | Под какой блок |
|---|---|---|
| Карусель — по одной новости | Одна запись целиком, смена по «Время на новость, с» (3–120), «Переход»: Плавно / Сдвиг / Без анимации | 16:9, квадрат, вертикаль |
| Свободная компоновка | Одна запись; блоки Фото, Заголовок, Текст, Источник, Дата, Рубрика расставляются мышью на холсте конструктора (красный уголок — размер, клик по блоку — шрифт, цвет, выравнивание). Раскладки-основы: Фото слева, Фото справа, Фото фоном, Фото сверху, Только текст по центру | Фирменный макет, мокапы (prtv-design-mockups) |
| Лента — вертикальная прокрутка | Колонка карточек, «Скорость прокрутки» 1–10 | Высокая колонка сбоку |
| Сетка карточек | Несколько записей сразу; число колонок и рядов подбирается под блок | 16:9, большой экран в холле |
| Бегущая строка заголовков | Строка заголовков с подписью источника | Полоса внизу экрана |

**Заготовки** — Новости с фото, Фото фоном, Крупные заголовки, Лента в колонку, Плитка, Бегущая строка — заменяют все настройки вида; ленты и отбор записей остаются. Удобная отправная точка, потом подстроить.

«Обновление данных, с» (30–3600, по умолчанию 120) — как часто экран спрашивает свежие записи; сами ленты сервер перечитывает не чаще раза в 5 минут.

## 5. Что показывать, эффекты, оформление

- **Что показывать:** Картинка (Положение: Сверху / Снизу / Слева / Справа / Фоном; Вписывание: Заполнить / Целиком / По картинке), Текст новости и «Строк текста, не больше», Дата («5 мин назад», Время, Дата, Дата и время, Не показывать), Название источника, Рубрика, Шапка над лентой (пустой текст шапки — названия лент).
- **Эффекты:** Анимация заголовка (Проявление, Выезд снизу, Из размытия, По буквам, Печатная машинка), Медленный наезд на фото, Полоска времени до следующей новости, Тень под текстом (для текста поверх фото), Метка «новое» для записей не старше N часов.
- **Оформление:** Тема — Карточки / **Без подложки** / Тёмная; Шрифт — Inter, Roboto, Montserrat, PT Sans, Open Sans, Oswald, Arial; цвета «Фон карточки», «Текст», «Акцент»; **«Прозрачный фон вокруг карточек»**; Выравнивание текста; Размер шрифта (24–96, по умолчанию 44), Скругление (0–48), Отступ (0–120).
- Размер шрифта, скругление и отступ заданы для экрана 1920×1080 и сами масштабируются под блок — по меньшей стороне. На вертикали текст того же размера, что на 16:9; в узкой полосе шрифт дополнительно увеличивается; нижний порог — 16 px. Длинный текст режется по целым строкам с многоточием: сначала текст, потом заголовок.
- Под фото слайда: «Тема → Без подложки» + «Прозрачный фон вокруг карточек» + альфа 0 у фона HTML-блока, цвет текста под фото, «Тень под текстом».
- Галочка «Мелкая подпись об ошибке в углу» — только для отладки. Без неё при сбое экран ничего не пишет: до первой загрузки блок прозрачный, потом остаются прошлые новости.

## 6. Размер блока

| Задача | Блок на слайде 1920×1080 | Режим |
|---|---|---|
| Новость с фото, главный элемент | 16:9 или квадрат, от 960×540 | Карусель, Свободная компоновка |
| Колонка новостей сбоку от меню | ~600×960 | Лента |
| Экран новостей в холле | весь слайд | Сетка карточек |
| Полоса внизу под основным контентом | ~1728×164 внутри полосы 1920×200 | Бегущая строка |

Проверять в предпросмотре конструктора на ближайшем размере (блок 600×300 и полоса 1920×200 показывают, что останется читаемым).

## 7. Рецепты

### 7.1. Все новости спорта из пяти лент

1. «+ Добавить ленту» пять раз (адреса проверены «Проверить» 10.10.2026): `https://www.championat.com/rss/news/`, `https://www.sports.ru/rss/main.xml`, `https://lenta.ru/rss/news/sport`, `https://rsport.ria.ru/export/rss2/index.xml`, `https://www.gazeta.ru/export/rss/sport.xml`.
2. Подписи короткие: Чемпионат, Sports.ru, Лента.ру, РИА Спорт, Газета.Ru.
3. «Несколько лент на экране → Чередовать» — на экране будут все пять изданий, а не только самое частое.
4. «Исключить слова»: ставки, ставка, букмекер, букмекеры, прогноз, коэффициент, трансляция — и фамилии политиков, если на экране их быть не должно.
5. «Только новости с картинкой», Тип — Карусель, Картинка «Фоном», Медленный наезд, Тень под текстом, Roboto 64, яркий акцент.

### 7.2. Новости только про свой город

1. Две-три общие ленты (например, `https://lenta.ru/rss/news`, `https://ria.ru/export/rss2/archive/index.xml`) и городская (`https://www.m24.ru/rss.xml`, `https://www.mos.ru/rss` для Москвы).
2. «Только со словами» — название города **во всех падежах** и прилагательные: Москва, Москвы, Москве, Москву, Москвой, московский, московская, московские, москвичи.
3. «Исключить слова» — суд, арест, задержали, ДТП, погиб, погибли и т. п.; список пополнять по тому, что проходит.
4. Тип — Лента, «Шапка над лентой» с текстом «<Город> сегодня», «Дата → Время».

### 7.3. Бегущая строка в полосе внизу экрана

1. Нижняя полоса слайда ~1920×200 (фон полосы — картинкой или прямоугольником на слайде). HTML-элемент ~1728×164 внутри полосы, по горизонтали в безопасной зоне.
2. Тип — «Бегущая строка заголовков», «Скорость прокрутки» 3–4, ленты с короткими подписями (Мос.ру, Путешествия, Наука).
3. «Размер шрифта» подобрать по предпросмотру «полоса · 1920×200», чтобы строка заполнила высоту: в полосе ~160–200 px — около 90–96.
4. Тема «Без подложки», «Прозрачный фон вокруг карточек», светлый текст на тёмной полосе.

### 7.4. Ограничения, о которых сказать заранее

- **Бегущая строка — только заголовки.** Текст новости в ней не показывается.
- **Информер появляется через несколько секунд после смены слайда** (обычно 3–6 с): плеер загружает iframe при показе слайда. Слайду с информером давать не меньше 15–20 с; на фоне под блоком не оставлять «дыру», которая видна до загрузки.
- Строка в полосе не растягивается на высоту блока сама — высоту заполняет размер шрифта.
- Время в подписях («5 мин назад», «сегодня в 18:30») считается по часам устройства показа; часового пояса в настройках нет.
- Сетка показывает одну страницу записей (сколько помещается), без перелистывания.
- Лента в низком блоке показывает карточки по одной, а не прокручивает.
- Экрану нужна сеть при каждом показе; если сайт-источник недоступен, сервер отдаёт сохранённую копию (до 3 суток), а экран держит прошлые записи.

## Чего не делать

- Не ставить общую новостную ленту на экран клиники, школы, детского кафе — только тематические ленты и фильтр.
- Не надеяться, что одно слово в фильтре найдёт все формы — перечислять.
- Не обещать текст новостей в бегущей строке.
- Не ставить два движущихся информера на один слайд: второй — с «Время на новость» 120 с, чтобы за показ слайда не менялся.
- Не брать ленту без проверки кнопкой «Проверить».
- Не оставлять включённой «Мелкую подпись об ошибке» на рабочем экране.
