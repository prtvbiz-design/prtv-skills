# Информер «Лента» PRTV

Главная слабость большинства слайд-шоу — данные, вбитые в слайды: цены, расписания и даты акций устаревают, а каждая правка — это вход в редактор. «Лента» переносит эти данные туда, где бизнес их и так ведёт, — чаще всего в Google Таблицу, которую правят с телефона, — и рисует на слайде. Дизайн слайда остаётся, данные обновляются сами.

Конструктор (v1.0): https://s.prtv.su/wp-content/plugins/prtv-informer-rss/index_in.php — адрес может переехать в каталог информеров https://s.prtv.su/informery. Конструктор выдаёт `<iframe>` 100%×100%, который вставляется в **HTML-блок** на слайде; размер и положение задаются на слайде (общие правила — prtv-widgets).

## 1. Источники

В одну ленту можно добавить несколько источников: записи объединяются и сортируются по дате.

| Источник | Что вводить | Для чего |
|---|---|---|
| RSS | адрес ленты | новости отраслевого СМИ, города, блога |
| Google Таблица | ссылка из адресной строки (доступ на просмотр по ссылке) | прайсы, расписания, объявления, вакансии, меню |
| Курс ЦБ РФ | ничего | курсы с флагами и изменением за день |
| ВКонтакте | vk.com/адрес или короткое имя | посты своего сообщества |
| Google Новости | слова, например «кофейня Москва» | новости по теме, когда нет готового RSS |
| Википедия | `otd` — этот день, `potd` — фото дня | спокойный нейтральный «интересный» контент |
| Календарь iCal | ссылка на .ics / адрес iCal | события, занятия, переговорные, конференции |
| Производственный календарь | ничего | рабочие и праздничные дни месяца |

Фильтры: число записей, давность в часах, минимальная длина текста, только со словами, исключить слова, только с картинкой, порядок (сначала новые / старые).

## 2. Режимы показа

- **Карусель** — по одной записи, время на запись и переход настраиваются.
- **Свободная компоновка** — по одной записи; фото, заголовок, текст, источник, дата, рубрика расставляются на холсте.
- **Лента** — вертикальная прокрутка.
- **Сетка карточек** — несколько записей сразу.
- **Бегущая строка** заголовков.
- **Расписание** — события по дням (для iCal).
- **Производственный календарь** — месяц целиком или две недели крупно.
- **Курс валют** — таблица с флагами, названиями, стрелкой и дельтой.
- **Услуги и цены** — прайс из таблицы (название … цена), группировка по разделам, примечание под названием, 1–3 колонки, строки или плитки.
- **Таблица как есть** — колонки таблицы на экране, строка заголовков и полосы по желанию.

Оформление: темы (карточки / без подложки / тёмная), 7 шрифтов, цвета карточки, текста и акцента, прозрачный фон, выравнивание, размер шрифта для 1920×1080 с масштабированием под блок, скругление, отступ; эффекты — анимация заголовка (проявление, выезд снизу, из размытия, по буквам, печатная машинка), Ken Burns на фото, полоска времени до следующей записи, тень под текстом на фото, метка «новое», шапка над лентой.

## 3. Рецепты Google Таблиц

Одна таблица — одна задача экрана, первая строка — заголовки, одна строка — одна позиция. Хозяин правит таблицу, экран следует за ней.

| Задача | Режим | Колонки |
|---|---|---|
| Прайс (салон, мойка, клиника, химчистка, услуги отеля) | услуги и цены | раздел · название · цена · примечание |
| Меню дня / столовая | услуги и цены | раздел · блюдо · цена · вес |
| Расписание врачей или мастеров на неделю | таблица как есть | специалист · кабинет · Пн … Вс |
| Свободные окна сегодня | таблица как есть | время · услуга · мастер |
| Трансферы и экскурсии на завтра (отель) | таблица как есть | время · маршрут · место сбора · цена |
| Статус заказа по талону (мойка, СТО) | таблица как есть | № талона · этап (без имён и госномеров) |
| Срочное объявление | карусель или бегущая строка | одна строка текста; удалили строку — блок пуст |
| Акции недели | карусель / свободная компоновка | заголовок · текст · ссылка на картинку · действует до |
| Вакансии | карусель | должность · график · зарплата · контакт |
| Цены на топливо (АЗС) | таблица как есть | топливо · цена |
| Загруженность зала по часам | таблица как есть | час · загрузка |

Правила: цена на экране совпадает с кассой и печатным прайсом; у акций пишем «действует до <дата>»; никаких персональных данных (имена гостей и пациентов, госномера) в таблице, которая кормит общий экран.

## 4. Отрасли — по строке

Отель — услуги и цены, трансферы, мероприятия (iCal), курс ЦБ с юанем, срочные объявления, Википедия «этот день» для канала в номерах. Мойка / СТО — прайс по типам кузова, статус по талону, авто-новости через RSS/Google Новости. Красота — прайс, свободные окна, портфолио из ВК, мастер-классы (iCal). Магазин — акции недели, вакансии, режим работы в праздники по производственному календарю. Клиника — расписание врачей, прайс платных услуг, школы для пациентов (iCal). Фитнес — расписание групповых (iCal или таблица), абонементы, загруженность зала. Офис / производство — производственный календарь, именинники, меню столовой, деловые новости и курсы. Подъезд — отключения и собрания (таблица), вывоз мусора (iCal). Полные схемы экранов — в отраслевых скиллах (hotel-digital-signage, auto-service-signage, beauty-salon-signage, retail-store-signage, clinic-signage, fitness-club-signage, office-signage).

## 5. Проверки

- Сначала открыть ссылку информера во вкладке браузера, потом — на целевом ТВ. Лента требует сети при каждом показе.
- Google Таблица должна быть доступна по ссылке на просмотр; закрытая таблица не покажет ничего.
- ВКонтакте и Google Новости зависят от того, пускает ли сеть заведения к этим сервисам, — проверять на месте.
- Размер HTML-блока — под режим: бегущая строка — полоса; карусель с фото — 16:9 или квадрат; прайс — высокая колонка.
- Прозрачный фон + альфа 0 у фона элемента, если лента лежит на фото (prtv-widgets §5).

## Чего не делать

- Не вбивать цены и расписания в слайды, если их может отдавать таблица.
- Не класть персональные данные в таблицу общего экрана.
- Не ставить две движущиеся ленты на один слайд.
- Не пускать сторонние новости на экран клиники или детского учреждения без фильтра слов.
