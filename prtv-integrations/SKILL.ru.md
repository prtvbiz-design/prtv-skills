# PRTV: живые данные, расписание, статистика

Экран, который обновляется сам, не устаревает. Правило: всё, что меняет персонал (цены, стоп-лист, расписание, акция дня), брать из системы, где он и так это меняет. Данные из Google Таблиц, RSS, iCal, курсов ЦБ и производственного календаря — информер «Лента», скилл **prtv-feed-widget**.

## 1. Кассовые системы — меню и цены автоматически

Подключение один раз в prtv.pro: **Настройки → Сервисы ресторанов** (prtv.pro/settings). На слайде — информер **«Ресторанное меню»**: выбрать сервис, блюда (по умолчанию все), число в ряду, шрифт и размер названия и цены отдельно, фото (4 варианта расположения, отступ, размер, скругление).

- **R_Keeper**: в R_Keeper «Интеграции → Подключение по API → Добавить подключение по API» → скопировать client_id и client_secret → в PRTV поля «Номер стенда (Client ID)» и «Токен (Client Secret)».
- **iiko**: «Внешние меню → Добавить → Сгенерировать меню» (там же правятся блюда, фото, порядок) → «Настройки Cloud API → Интеграции → Добавить» (внешнее меню, источник цен, точка) → ключ API в PRTV. На слайде выбрать организацию и меню. Если нет ID категории цен — `00000000-0000-0000-0000-000000000000`.
- **Quick Resto**: логин и пароль из «Предприятие → Настройки». Quick Resto не отдаёт фото блюд — их ставят на слайд вручную.
- Учётные данные кассы вводит владелец; агент их не спрашивает и не хранит.

## 2. Таблицы и календари

- **Excel / таблица**: элемент «Таблица» (новая или импорт из Excel) или онлайн-таблица через HTML-блок. Правки в таблице доходят до ТВ за несколько минут. Кейсы: меню столовой на каждый день, расписание врачей (ФИО, специальность, кабинет, дни), график смен и KPI на производстве, расписание мастеров салона.
- **Google Таблица** с ценами и расписаниями — через «Ленту» (prtv-feed-widget).
- **Google Календарь**: в календаре «Доступ → Сделать общедоступным», в «Интеграции календаря» скопировать ID → страница https://s.prtv.su/informery/google-kalendar (вид день / неделя / месяц, шрифт, цвета) → код в HTML-блок. Так выводят расписание уроков, приём врачей, смены, дни рождения сотрудников.
- **Google Презентация**: Файл → Поделиться → Опубликовать в интернете → Встроить → iframe в HTML-блок.

## 3. Соцсети — контент приходит сам

- Элемент ленты: Telegram (каналы и чаты), ВКонтакте, Одноклассники, RSS. ВК один раз подключить в настройках аккаунта (prtv.pro/settings). Настраиваются число постов, порядок, картинка, частота обновления.
- Приём: **пост = слайд**. Повар публикует блюдо дня в Telegram-канал, салон — акцию в группе ВК, и она появляется на экране без правки слайд-шоу.
- Instagram, Facebook и Twitter в старых шаблонах в РФ не работают — заменять.

## 4. Видео и музыка

- **YouTube**: ролик, Shorts, плейлист или **страница канала** — тогда всегда идёт последнее видео канала (стрелка «вверх» на пульте — предыдущее). Если ролик не играет — проверить `autoplay=1` в коде; размер встроенного видео задаётся width/height в коде, а не мышью. Длительность слайда с видео увеличить вручную (по умолчанию 30 с).
- **VK Видео** (замена YouTube): ВК подключить в профиле PRTV, у ролика открыть доступ «Все пользователи» или по ссылке, при необходимости включить повтор, кнопка «Видео» → ссылка.
- **Свой видеохостинг PRTV** (платная функция): файлы avi/mp4 до 300 МБ, любой длительности, без рекламы и чужих логотипов; «Видео → Kinescope → Выбрать видео». Vimeo тоже работает; RuTube не поддерживает автозапуск.
- **Фоновые трансляции**: круглосуточные YouTube-эфиры (lofi, кафе-музыка, природа, веб-камеры городов, NASA) и эфир ТВ-каналов через «Поделиться → Код вставки плеера» на RuTube.
- **Музыка**: встроенные радиостанции старой версии отключены с 28.04.2026. В PRO — радио «Кофейня» в настройках слайд-шоу (инструментальная музыка, подбор по дню недели и времени суток). Альтернатива — информер «Радио без рекламы», https://s.prtv.su/informery/radio-free (жанры Instrumental, Acoustics, Indie, Nu Jazz, Smooth, Background): звучит на всём слайд-шоу, на каком бы слайде ни стоял; плеер можно спрятать под картинку. Другие плееры (Яндекс Музыка, Mixcloud с Autoplay) — через HTML.

## 5. Камеры и карты

- **IP-камера или регистратор (RTSP)**: нужен статический внешний IP; камера с RTSP (проверены HiWatch, Hikvision, TP-Link, D-Link, iCSee); на роутере проброс порта 554 (для нескольких камер внешние 5541, 5542…). Ссылка вида `rtsp://логин:пароль@внешний_ip:порт/…` (HiWatch: `/ISAPI/Streaming/Channels/101`, 101 — камера 1 поток 1, 201 — камера 2). Браузер RTSP не играет — поток переводят в HLS через rtsp.me и вставляют полученный iframe в HTML-блок. Идеи: кухня ресторана, детская площадка у подъезда, пляж для турагентства.
- **Отзывы Яндекс Карт**: карточка организации → «⋮ → Поделиться» → код виджета отзывов → HTML-блок.
- **Панорамы улиц Яндекс**: «Панорамы и фото» → точка → «Поделиться» → «Виджет с картой» → HTML-блок (снимок не живой, год съёмки в углу).
- **Карта с пробками**: адрес из настроек слайд-шоу подставляется сам; на одном слайде можно держать несколько карт (отель → аэропорт, достопримечательности).
- **OpenStreetMap**: слой (например, транспортный) → «Вставить на сайт» → HTML.

## 6. Голосование

Информер голосования (https://s.prtv.su/golosovanie): на экране вопрос и QR, гости голосуют со смартфона, результат — столбцы или круговая диаграмма. Чтобы итоги обновлялись, длительность слайда 60 с. Идеи: блюдо следующего месяца, выбор музыки, опрос жильцов.

## 7. Потоки — разные слайд-шоу по расписанию (платная функция)

- «Добавить поток» → название → клик по ячейке «день × час» → выбрать слайд-шоу и время окончания; строка «Весь день» — одно слайд-шоу на день недели; повтор по неделям.
- **Фоновое слайд-шоу** идёт, когда в расписании ничего не задано.
- На ТВ поток открывается по своему коду в приложении или по ссылке в браузере; можно синхронно на нескольких ТВ.
- Сценарии: завтраки до 12:00, бизнес-ланч 12–16, основное меню с 17:00; отель — завтрак, экскурсии, ресторан и бар, ночью справка; школа и офис — отдельное слайд-шоу-поздравление на дату дня рождения.
- **Подборка** — несколько слайд-шоу под одним номером подряд.

## 8. Статистика показов (платная функция)

Считает показы любого элемента: видео, картинки, бегущей строки, поста. Аргумент для внешнего рекламодателя: аптека продаёт слот фармкомпании, АЗС — партнёру, бизнес-центр — арендатору, супермаркет — поставщику.

## 9. Лицензии — ловушка привязки

Первая лицензия бесплатна: одно слайд-шоу на трёх экранах одновременно. Дополнительные — в разделе «Лицензии» (prtv.pro/licenses): выбрать количество → оплатить → **обязательно нажать «Продолжить»** → **привязать лицензию к слайд-шоу** кнопкой в списке. Оплаченная, но не привязанная лицензия водяной знак не снимает. Баланс — в «Настройках профиля». Платные функции (видеохостинг, потоки, статистика) подключаются там же и не обязательны.

## 10. Экран, который зарабатывает

- Партнёрская программа Билайн (с сентября 2026): владелец экрана создаёт персональный QR на partners.beeline.ru, показывает его на слайде и получает вознаграждение за подключённых абонентов.
- Реклама соседей и партнёров (такси, «трезвый водитель», цветы, химчистка в подъезде) — слот со статистикой показов.

## Чего не делать

- Не перепечатывать цены вручную, если они уже есть в кассовой системе.
- Не ставить видео с автозапуском без проверки на самом ТВ.
- Не держать камеру в открытом доступе без пароля; не показывать на экране лица посетителей без их согласия.
- Не обещать клиенту цены платных функций — смотреть актуальные в разделе «Лицензии».
