# Настройки слайда в конструкторе PRTV

Слайд-шоу PRTV — это ротация слайдов; каждый слайд — один полный экран со своим таймингом, переходом, фоном и умолчаниями для элементов, которые на него кладут. Этот скилл закрывает средний уровень иерархии: слайд-шоу → **слайд** → элемент. Элементы — в prtv-element-layout, общая карта редактора — в prtv-editor-overview. Всё ниже проверено в браузере.

## 1. Полоса миниатюр

Слайды лежат в горизонтальной полосе внизу редактора (`.bottom-layer`, высота 160 px). Каждая миниатюра — полная уменьшенная копия слайда с **теми же id элементов**, что и на холсте, поэтому всё слайд-шоу можно проинвентаризировать по полосе, не переключая слайды. Единственное исключение: информеры в миниатюрах не рендерятся — вместо них заглушка «iframe blocked».

**Переключение активного слайда** — клик по миниатюре. Клик иногда срабатывает со второй попытки; проверять по DOM (какой узел слайда показан на холсте), а не на глаз. Каждая кнопка левой панели добавляет элемент на *текущий активный* слайд, поэтому перед добавлением всегда подтверждать, какой слайд активен.

**Перестановка** — драг миниатюры вдоль полосы; порядок меняется сразу. Есть и клавиатурный драг (доступность). Не начинать драг по миниатюре, если не собираетесь переставлять: незавершённый драг оставляет миниатюру сдвинутой.

**Добавление слайда** — кнопка добавления у полосы либо **«Слайд из макета»** — вставить слайд, сохранённый ранее как макет (§3).

## 2. Четыре hover-кнопки миниатюры

При наведении настоящей мышью над миниатюрой появляется ряд из четырёх иконок, слева направо:

| # | Кнопка | Что делает |
|---|---|---|
| 1 | Настройки (шестерёнка) | Открывает панель настроек слайда слева (§4). |
| 2 | Сохранить в качестве макета | Открывает окно «Укажите название шаблона». Это **не** обычное сохранение — сохраняется всё автоматически; здесь создаётся переиспользуемый макет. |
| 3 | Дублировать | Сразу дублирует слайд рядом с оригиналом. |
| 4 | Удалить (красная корзина) | Сразу удаляет, без окна подтверждения. |

Две ловушки для агента:

- Иконки появляются только при **реальном наведении курсора**. Синтетическое событие `mouseenter` их не показывает; перед кликом физически провести указатель над миниатюрой.
- Кнопка удаления стоит ровно там, куда попадает неосторожный «клик где-то рядом с полосой». Не кликать около полосы «на всякий случай».

**Правый клик по миниатюре не открывает своего меню** — только нативное меню браузера. Все действия со слайдом — четыре hover-кнопки. (У элементов иначе: правый клик по элементу открывает меню из семи пунктов — см. prtv-element-layout.)

## 3. Макеты

«Сохранить в качестве макета» запоминает раскладку текущего слайда под именем. Сохранённые макеты перечислены в **«Слайд из макета»** и вставляются новым слайдом со всеми элементами. Макет удобно держать как фирменную раскладку (плашка заголовка, сетка карточек, логотип, часы) и быстро плодить слайды одной семьи.

## 4. Панель настроек слайда

Открывается шестерёнкой на миниатюре. Три раздела.

### «Основные»

| Поле | По умолчанию |
|---|---|
| Скрывать полосу загрузки (Нет / Да) | Нет |
| Длительность показа, сек | 30 |
| Цвет полосы загрузки | `#3f51b5` |
| Фон полосы загрузки | `#b6bce2` |
| Эффект перехода (список) | «Без эффекта» |
| Длительность перехода (степпер) | появляется, когда задано значение |

**Длительность показа** — число, к которому привязана любая анимация на слайде: эффекты появления должны успеть отыграть и оставить паузу на чтение внутри неё, а период зацикленных анимаций HTML-блока должен укладываться в неё, чтобы цикл не обрывался посередине при смене слайда (см. prtv-html-block-animation).

Полоса загрузки — тонкая линия, которая бежит по экрану за время показа слайда; на меню-бордах и промо-экранах её лучше скрывать, там это визуальный шум.

### «Стили по умолчанию» — фон самого слайда

| Поле | По умолчанию |
|---|---|
| Цвет фона | `#ffffff` |
| Фоновое видео | URL (`https://…`) и «Без звука» Нет / Да |
| Фоновое изображение | загрузка файла через выбор файла |
| Отображение фона (список) | «Растянуть» |

### «Стили элементов по умолчанию» — для новых элементов этого слайда

Цвет фона `#ffffff`, фоновое изображение (файл), отображение фона «Растянуть», непрозрачность (степпер), шрифт ARIAL, размер шрифта 24, цвет текста `#000000`.

Эти умолчания применяются к элементам, **добавленным после** их установки; существующие элементы не меняются. Задать здесь фирменный шрифт, кегль и цвет один раз, до добавления элементов, — значит не править потом каждый текст. Шрифт конструктора по умолчанию — Arial; бренд-слайду шрифт нужно ставить явно.

**Чего в панели нет:** имени слайда, расписания или условий показа, ориентации. Слайд идентифицируется только позицией; расписание — не настройка слайда.

## 5. Эффекты перехода — 15 значений

По порядку списка, как подписано в редакторе:

Без эффекта · Затухание · Сдвиг влево · Сдвиг вверх · Сдвиг вправо · Сдвиг вниз · Приближение · Отдаление · Выгнутный влево · Выгнутный вправо · Вогнутый влево · Вогнутый вправо · Конвейер · Колесо · Появление.

Для вывесок, которые читают (меню, прайсы), безопасный выбор — «Без эффекта» или «Затухание»; объёмные переходы привлекают внимание к смене кадра, а не к содержимому, и на телевизионном железе выглядят иначе, чем на десктопе.

## 6. Фон слайда — три способа

1. **Настройки слайд-шоу по умолчанию** (кисточка в верхней панели): цвет, картинка или видео для *всех новых* слайдов; «Применить ко всем» переносит их на каждый существующий слайд. Правый клик по пустому месту холста открывает ту же панель.
2. **Настройки слайда** (шестерёнка на миниатюре → «Стили по умолчанию»): цвет, картинка (файл) или видео (URL, можно без звука) только для этого слайда.
3. **Элемент «Картинка»**, растянутый на 1920×1080 с глубиной 0 — когда поверх фона нужны слои или эффекты (см. prtv-element-layout). Это единственный способ положить растянутую картинку *под* остальные элементы с полным контролем.

Фон из настроек слайда рисуется на глубине 0 и ничего не прячет. Родного градиента нет — загрузите готовую картинку с градиентом.

Картинки загружаются только через выбор файла; галереи ранее загруженного нет, индикатора загрузки нет — URL картинки появляется в DOM через несколько секунд. Крупные изображения при загрузке уменьшаются примерно на четверть.

Фоновое видео: вставить `https://`-адрес в поле и выбрать «Без звука» — Да для беззвучного воспроизведения. Требования к бесшовной петле — в prtv-video.

## 7. Умолчания слайд-шоу и настройки слайда

Две похожие панели легко перепутать:

| | Умолчания слайд-шоу (кисточка или правый клик по холсту) | Настройки слайда (шестерёнка на миниатюре) |
|---|---|---|
| На что действует | новые слайды и новые элементы всего слайд-шоу; «Применить ко всем» — на все существующие слайды | только этот слайд |
| Разделы | стили нового слайда, стили новых элементов | основные, фон слайда, стили элементов по умолчанию |

«Применить ко всем» перезаписывает фон и умолчания у каждого слайда. Использовать только для осознанной глобальной правки — смены фирменного цвета, общего фона — и никогда «чтобы починить один слайд».

## 8. Чтение состояния слайда из DOM

- Узел слайда на холсте: `id="slide-<id>"`.
- Миниатюры в `.bottom-layer` несут те же id элементов, что и холст — по ним считают элементы на слайде, находят, к какому слайду относится элемент, замечают пустые слайды.
- Публичная страница плеера: класс body `active-slide-<id>` называет слайд, который сейчас на экране. Опрашивая его, можно подтвердить порядок ротации и длительности, не глядя на экран.
- Собственные настройки слайда (длительность, переход, фон) показаны в панели — открыть шестерёнку и прочитать поля.

Инвентаризация элементов всего слайд-шоу с их id слайдов доступна через локальное хранилище только для чтения, описанное в prtv-editor-overview.

## 9. Проверка результата

Холст редактора показывает неподвижный слайд. Ротация, переходы, длительности и полоса загрузки видны только в **предпросмотре** (кнопка «глаз» в верхней панели) — ждать хотя бы одну полную длительность на слайд. Публичная страница ТВ в десктопном браузере может надолго «залипнуть» на первом слайде при правильных данных; эталон — предпросмотр, публичная страница — вторичная проверка.

Сохранение автоматическое. Кнопки «Сохранить» нет; после правки появляется «Сохранено». Для уверенности — перезагрузить страницу: сохранено то, что пережило перезагрузку. Undo (Ctrl+Z) работает только в пределах сессии страницы; истории версий нет, удалённый слайд после перезагрузки не вернуть — перед рискованными правками дублировать.

## Чего не делать

- Не использовать «Сохранить в качестве макета» как кнопку сохранения — сохраняется автоматически, кнопка создаёт макет.
- Не кликать рядом с полосой миниатюр без цели: там по наведению появляется удаление без подтверждения.
- Не доверять синтетическому наведению — четыре кнопки показываются только при настоящем движении курсора.
- Не добавлять элементы, не подтвердив по DOM, какой слайд активен.
- Не нажимать «Применить ко всем», чтобы поправить один слайд.
- Не судить об информерах по миниатюрам — там заглушки.
- Не искать в настройках слайда имя, расписание и ориентацию — их там нет.
- Не ставить переход на слайд с плотным текстом только потому, что он есть в списке.
