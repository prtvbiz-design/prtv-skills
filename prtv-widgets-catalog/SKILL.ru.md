# Каталог информеров PRTV

Все конструкторы живут по адресам `https://s.prtv.su/informery/<страница>`, файлы рендера — `https://s.prtv.su/informers/<тип>/<файл>.php`. Любой embed — один и тот же тег с разным `src`:

```html
<iframe src="https://s.prtv.su/informers/<тип>/<файл>.php?<параметры>" frameborder="0" width="100%" height="100%" style="overflow:hidden;"></iframe>
```

Универсальные правила (цвета `%23`, города кириллицей, `encodeURIComponent`, прозрачность, размеры) — в prtv-widgets и ниже не повторяются. Шрифты: большинство старых информеров принимают один из 29 Google-шрифтов (Anton, Bad Script, Comfortaa, Indie Flower, Fira Code, Forum, Jura, El Messiri, Kurale, Kelly Slab, Lobster, Marck Script, Neucha, Open Sans, Orbitron, Oswald, Pangolin, Play, Poiret One, Pacifico, Press Start 2P, Pattaya, Roboto, Ruslan Display, Russo One, Rubik Mono One, Seymour One, Stalinist One, Underdog); новое семейство (карточка акции, луна, рабочий день) — 7 (Roboto, Open Sans, Oswald, Comfortaa, Play, Russo One, Pacifico). Для чтения издалека — Russo One, Anton, Oswald.

## 1. Часы — два разных информера

**[A] «Часы»** — конструктор `/chasy`, файлы `clock/<тип>.php`, **21 тип**, настраиваются цвета, шрифты, размеры. Работает без источника данных. Конструктор не пошаговый: вкладка «тип» с 21 превью и вкладка «настройки»; у каждого типа своё поле с кодом.

**[B] «Аналоговые часы (выбор циферблата)»** — конструктор `/analogovye-chasy-vybor-cziferblata`, файлы `analog_clocks/index<N>.php`, N = 1…30, **30 готовых циферблатов**; единственный параметр — `city`. Цвета, шрифты, размер не меняются (любой лишний параметр игнорируется). Пропорция 1:1.

Выбор: готовый тематический дизайн (детский, римский, спортивный) → [B]; своя палитра или имя заведения на часах → [A]. Задача со словом «детск…» — сначала смотреть [B]. Имя и слоган несёт только `clock_analog` в [A].

**Правило пропорции:** квадрат 1:1 — `clock_analog`, `analog2–4`, `cube`, `progress` и все 30 циферблатов; широкий 2:1 — все `digital*`, `flip`, `flip1`, `neon`, `neon2`, `glitch`, `rotate`, `skeleton`, `progress1`, `analog5`.

## 2. Погода — 7 видов

Конструктор `/openweather`, файлы `weather_openweathermap/<файл>.php`. Данные OpenWeather через сервер PRTV — телевизор общается только с s.prtv.su; ключ не нужен. Единицы °C, м/с, мм рт. ст., подписи по-русски; параметров для их смены нет.

| Вид | Файл | Вид | k (высота/ширина) |
|---|---|---|---|
| 1 | weather_wide_flexible.php | широкий светлый баннер: город, дата, время, состояние, ветер/влажность/давление | ≈ 0,28 |
| 2 | weather_narrow_flexible.php | компактный светлый: дата, температура, ветер/влажность/давление | ≈ 0,55 |
| 3 | weather_wide_litle_flexible.php | однострочная сверхширокая лента | ≈ 0,24 |
| 4 | weather_color_flexible.php | цветная карточка, почти квадрат — **цвета зашиты** (белый фон, чёрный текст), пикеры и прозрачность отключены; только иконки и шрифт | ≈ 0,85 |
| 5 | weather_5.php | тёмный широкий, температура + max/min дня | ≈ 0,45 **только при ширине бокса ≥ 1050 px** — ниже вёрстка переключается на мобильную и обрезается |
| 6 | weather_6.php | тёмная карточка с крупной температурой, город, дата, ветер/влажность/давление | 0,73 (измерено) |
| 7 | weather_7.php | тёмный квадрат, почасовой прогноз | 1,08 (измерено) — чуть выше квадрата |

Параметры: `city` (обязателен, кириллицей), `fon_table` (фон), `font_text` (текст), `font_tempo` (температура/данные), `transpar` 0/1, `font_family`, `type_img` (набор иконок: `img_7_svg`, `img_8_svg`, `img_9_svg`, `img_10_svg` или `img` для PNG) в паре с `img_tip` = `svg` или `png`. Подписи формы не совпадают с этими именами (форма `color_fon` → URL `fon_table`).

Известные ограничения: температура не округляется (например 20,79°); неверный город печатает на слайде фразу об ошибке; время в виде 1 может не быть живым локальным временем города — проверять. Прозрачность подтверждена на видах 1 и 7 (остаётся лёгкая подложка карточки, хорошо читается над фото); на 5 и 6 не проверялась.

Пример: `weather_wide_flexible.php?transpar=0&font_family=Oswald&type_img=img_7_svg&img_tip=svg&fon_table=%23f2f2f2&font_text=%23111111&font_tempo=%231565C0&city=Москва`

## 3. Обратный отсчёт

Конструктор `/countdown`, файл `countdown/timer.htm`. Четырёхшаговый мастер: 1) тип таймера («До даты» и другие) → далее; 2) дата `ДД/ММ/ГГГГ` и время `ЧЧ:ММ`; 3) дизайн — текст / плашка / круг — и галочки единиц; 4) код. Поля произвольной подписи нет — подпись делать родным текстовым элементом (≥ 40 px). Считает по часам устройства.

## 4. QR — меню, Wi-Fi, текст

Конструктор `/qr-infomer`, файл `qr_horeca/qr.php`. Режимы по `type`: `link` (URL), `wifi`, `text`. Параметры: `title` (подпись над кодом), `text` (URL или текст, закодированный), `wifi_name`, `wifi_pass`, `wifi_type` (`WPA`, `WPA2`, `WEP`, `nopass`), `font_family`, `font_text`, `font_title`, `fon_table`, `transpar`. Конструктор перегенерирует код при каждом вводе. Пароль Wi-Fi — часть URL; обращаться с embed соответственно. Давать коду запас: загрузки уменьшаются, телевизоры размывают края; модуль держать квадратным и ≥ 300 px на холсте 1920.

Пример (меню): `qr.php?type=link&title=Меню&text=https%3A%2F%2Fexample.com%2Fmenu&font_family=Oswald&transpar=1&font_text=%23ffffff`

## 5. Обычный календарь

Конструктор `/kalendar`, файл `calendar/calendar.php`. Сетка дат без событий; работает от даты устройства. Виды: `tip=1` сегодняшняя дата (крупно), `tip=2` табличный (сетка месяца, вертикальная), `tip=3` горизонтальная лента дней. `align` 1/2 для tip 2.

**Два независимых набора параметров месяца** — типичная ошибка:

- для `tip=1` и `tip=2`: `cur_month=MM/YYYY` (текущий), `month=MM/YYYY` (конкретный; игнорируется при заданном `cur_month`), `month_start` + `month_end` (диапазон);
- для `tip=3`: `gor_current_month`, `gor_month`, `gor_month_start` + `gor_month_end`.

Вид, которому передан только чужой набор, рисует пустой блок. Безопасный приём, как делает конструктор: передавать **оба** набора с одинаковым значением. `cur_month` фактически задаёт год; сам месяц берётся с часов сервера (на стыке лет возможно расхождение). Цвета: `fon_table`, `font_text`, `font_weekend` (по умолчанию `#bd0f0f`), `font_now` (сегодня, `#c0f788`), `transpar`, `font_family`.

Пример (горизонтальный): `calendar.php?tip=3&gor_current_month=09%2F2026&gor_month=09%2F2026&align=1&fon_table=%23f2f2f2&font_text=%23111111&font_weekend=%23bd0f0f&font_now=%23c0f788&font_family=Oswald&transpar=0`

## 6. Google-календарь

Конструктор `/google-kalendar`, файл `google_calendar/calendar.php`. Показывает события **публичных** Google-календарей; входа в аккаунт нет. Сделать календарь общедоступным в настройках Google Календаря и скопировать его идентификатор (`…@group.calendar.google.com` или gmail-адрес); несколько идентификаторов — через запятую. Личный календарь не публиковать — завести отдельный публичный только с событиями для экрана.

Параметры: `calendar_name` — идентификатор(ы) в **base64** (конструктор кодирует сам; если в base64 есть `+` или `/`, значение нужно URL-кодировать), `calendar_tip` — `dayGridMonth` (сетка месяца), `dayGridWeek`, `dayGridDay`, `listMonth` (список событий месяца); недокументированные, но рабочие: `listYear`, `listWeek`, `listDay`, `multiMonthYear` (проверять визуально — годовой список может начинаться с прошедших событий, а бокс не прокручивается). Цвета: `calendar_color_fon`, `calendar_data_color` (даты), `calendar_event_fon`, `calendar_event_color`, `calendar_today_fon`, `calendar_transpar`, `calendar_font_family`, `calendar_size_font` (em, 0–6 с шагом 0,5, по умолчанию 1).

Размеры: `dayGridMonth` требует высоту ≥ 1,0 × ширины (иначе внутренний скролл); `listMonth` вписывается в любой бокс, лишние строки скрыты снизу, дни без событий не показываются; неделя/день ≥ 0,6 × ширины.

Известные ограничения: в `listMonth` заголовки дней остаются на белом фоне, поэтому при тёмном `calendar_color_fon` и светлом `calendar_data_color` даты становятся невидимыми — для списочных видов брать **светлый фон с тёмными датами** (у сетки месяца этой проблемы нет). События иногда не загружаются, и информер показывает «нет событий» без ошибки — на слайдах предпочитать `dayGridMonth`, где пустая сетка выглядит нормально. Нужен доступ телевизора к Google API и CDN.

## 7. Курсы валют, драгметаллы, акции

**Курсы** — конструктор `course/index_in.php`, файлы `course/course1.php` (вертикальная таблица с флагами), `course2.php` (с датой в шапке), `course3.php` (горизонтальный). Параметры: `tip_value1..3` — ровно три кода валют (USD EUR CNY JPY GBP BYN KZT UAH TRY PLN RUB), `course_country` — `rf` (ЦБ РФ, серверно), `rkh` (НБ Казахстана, серверно), `rb` (НБ Беларуси — телевизор сам запрашивает nbrb.by; сетевой риск), `fon_table`, `font_text`, `font_curs` (цифры курса), `font_family`, `transpar`. Неверный код даёт битую строку без ошибки. Обновление раз в день (ЦБ РФ — после ~11:30 МСК на следующий день). Три валюты ≈ бокс 520×470 (course1); для других — измерить k.

**Драгметаллы** — `metal/course1.php` (вертикальный), `course2.php` (горизонтальный); всегда четыре металла (золото, серебро, палладий, платина, учётные цены ЦБ РФ, ₽/г). Те же цветовые параметры. Колонки «покупка/продажа» показывают одно число. **График** цен металлов (`metal_grafic`) зависит от внешней библиотеки графиков и в тестах возвращал пустые данные — не рекомендуется.

**Акции** — `stock/stock1.php?stocks=<тикеры,через,запятую>&color_fon=&color_text=&color_curs=&font_family=` — здесь **другие имена цветов**. Тикеры (строчными): aflt sber lkoh gazp five mgnt mtss rosn | aapl amzn googl ibm ko msft nflx pfe tsla. Часть тикеров застыла или пуста (`yndx`, `mail`, `fb`) — не использовать. Широкая таблица на шесть колонок: бокс от 1100 px по ширине. Грузит скрипт с CDN.

## 8. Карточка акции — счастливые часы, ланч, комбо, скидка до закрытия

Конструктор `horeca_action/index_in.php`, файл `horeca_action/action.php`. Карточка рисуется сервером, таймер клиентский; самодостаточна. Параметры: `type` 1–4, `title`, `subtitle`, `offer`, `price` (пустой скрывает блок цены), `start` и `end` `ЧЧ:ММ` (переход через полночь поддержан), `show_timer=1` («до начала» до окна, «до конца» внутри, затем переключается на завтра — карточка **видна всегда**; прятать её вне окна ротацией слайдов, а не информером), `transpar` (1 или пусто), `fon_table`, `font_text`, `font_accent`, `font_family` (7 шрифтов).

`type` задаёт текст бейджа и, для 2–4, цвет акцента: 1 = «СЧАСТЛИВЫЕ ЧАСЫ» (акцент из `font_accent` — единственный полностью настраиваемый тип); 2 = «БИЗНЕС-ЛАНЧ» зелёный `#2f8f46`; 3 = «КОМБО ДНЯ» оранжевый `#d98200`; 4 = «СКИДКА ДО ЗАКРЫТИЯ» тёмно-красный `#8b1e1e`. Для 2–4 слайд подбирать под этот цвет. Вписывается в любой бокс (рекомендуется от 500×280 до 900×520); на очень широких боксах шрифты перестают расти.

Пример: `action.php?type=3&title=Комбо%20дня&subtitle=Только%20сегодня&offer=Кофе%20%2B%20круассан&price=299%20%E2%82%BD&start=08:00&end=22:00&show_timer=1&transpar=1&font_text=%23FFF3E0&font_family=Oswald`

## 9. Луна, праздники, рабочий день

**Луна** — `moon_calendar/moon.php?type=1|2|3` (компактный / карточка / подробный), `transpar`, `fon_table`, `font_text`, `font_accent`, `font_family` (7). Эмодзи фазы, название фазы, лунный день, возраст, освещённость, рекомендация; расчёт приблизительный, о чём информер сам пишет. Любой бокс (420×420…700×640). Эмодзи на части ТВ показываются квадратами.

**Праздники** — `holidays/holidays.php?font_family=<шрифт>`. **Единственный** параметр — шрифт; текст зашит тёмно-серым на прозрачном фоне, на тёмных слайдах не читается — подложить светлую плашку. Список: праздники дня, исторические даты, именины; 2–6 строк; бокс от 500×280 с запасом по высоте (переполнение скрыто).

**Рабочий день** — `worktime/worktime.php?type=1|2|3&mode=day|friday|close&end=ЧЧ:ММ&transpar=&fon_table=&font_text=&font_timer=&font_family=`. `type` 1 компактный / 2 большая карточка / 3 «весёлый» с ротацией фраз. `mode=day` — «до конца рабочего дня» (в выходные — сообщение о выходном), `friday` — «до пятницы», `close` — «до закрытия» (работает семь дней). После `end` отсчёт сразу переключается на завтра — состояния «день окончен» нет; учитывать в расписании слайда. Время устройства; города нет. Любой бокс (520×300…900×500).

## 10. Карты и качество воздуха

Все грузят тайлы и данные со сторонних сервисов с телевизора при каждом показе; цвета не настраиваются; тёмных тем нет (на тёмных слайдах оформлять «окном» с рамкой); слайду давать ≥ 15 с.

- **Карта погоды** — `weather_maps/map.php?tip=1..5&lat=&lng=&zoom=1..10` (температура / осадки / облачность / давление / ветер). Часть тайлов по `http://` — https-плеер может убрать слой. Бокс от 800×600.
- **Погода на карте региона** — `weather_new/weather.php?city=<кириллицей>&transpar=&fon_table=&font_text=&font_tempo=&font_family=`: почасовая таблица прогноза плюс карта Google; карта может деградировать при исчерпании общей квоты.
- **Уровень загрязнённости (только Москва)** — `air/air.php?name=<станция>`, 23 московские станции (parkovaya, veshnyaki, marin, guryanova, ochakovskaya, melitopolskaya, troitsk, proletarskiy, cheremushki, mgu, shabol, kojuhovo, novokosino, spirid, suhar, spartakovskaya, narod_op, ostankino, glebovskaya, dolgoprud, turist, zelen_15, zelen_11). Официальный виджет WAQI, грузится с ТВ; светлые карточки, стили не меняются; бокс ≈ 1:1,2.
- **Карта чистоты воздуха Москвы** — `airmap/map.php`, без параметров (Яндекс-карта с метками станций).
- **Загрязнение воздуха в мире** — `airmap_world/map.php?lat=&lng=&zoom=` (zoom 8–11 для города, 4–6 для страны).

## 11. ТВ-программа, радио, расписание

- **ТВ-программа** — `tv/tv_informer.php?max=<N>&size=large|small&channel=<id,id,…>&color_fon=&color_font=&font_family=&transpar=`. ID каналов — из селекта конструктора (535 каналов, без поиска). `max` — передач на канал. Содержимое серверное; логотипы каналов по `http://` (смешанный контент). Лучшие места: холлы, отели, барбершопы.
- **Радио** — `radio/radio_informer.php?channel=<плейлист.m3u>&radio_color_fon=&controls=0|1`: 35 жанровых потоков (top_40, jazz, lounge, 80s …); `radio_free/radio.php` — серверная ротация треков. **Автозапуск со звуком на большинстве ТВ-плееров блокируется** — информер может молчать; проверять на устройстве и продавать звук осторожно.
- **Расписание (поезда, полёты)** — обёртка виджета Яндекс.Расписаний: `https://rasp.yandex.ru/informers/station/<ID>/?size=5|15|25&color=<N>&type=schedule|tablo`. Вокзалы Москвы: Киевский 2000007, Павелецкий 2000005, Белорусский 2000006, Ярославский 2000002, Савёловский 2000009, Рижский 2000008, Ленинградский 2006004, Курский 2000001, Казанский 2000003. Аэропорты: Внуково 9600215, Шереметьево 9600213, Домодедово 9600216, Сочи 9623547, Пулково 9600366, Нижний Новгород 9623052, Симферополь 9600396, Екатеринбург 9600370, Самара 9600380, Анапа 9623572. Любая другая станция Яндекса подставляется по её ID в том же формате. Высота фиксируется под `size` (5 строк ≈ 302 px). Яндекс может отвергать запросы из ЦОД и «ботов» — проверять на реальном ТВ.

## 12. Голосование, фотолента из облака, виджеты Яндекса

- **Голосование** — конструктор `informers/voter/`: форма, которая **создаёт опрос на сервере при каждой отправке** (тестовые отправки оставляют реальные опросы; редактирования и удаления из интерфейса нет). Поля: `type` bars/pie, `bar_color` (только для столбиков), `font_size`, вопрос, ответы. Результат: `voter/frame.php?qid=<N>` — экран показывает вопрос, варианты и QR; зрители голосуют с телефона; результаты появляются при следующем показе слайда. Надёжно сохраняются только три базовых поля ответов. Грузит скрипты с CDN.
- **Фотолента из облака** — `cloud/mail_ru.php?link=<публичная папка cloud.mail.ru>&number_time=<сек>`: слайд-шоу изображений из публичной папки Облака Mail.ru, заполнение по cover, смена каждые N секунд (по умолчанию 5). Самый простой клиентский канал контента — положил фото в папку, экран обновился. Зависит от формата публичных страниц облака.
- **Отзывы организации в Яндексе** — в Яндекс.Картах: организация → «⋯» → поделиться → скопировать код виджета отзывов → HTML-блок. Живой рейтинг и свежие отзывы.
- **Панорамы улиц** — Яндекс.Карты → панорамы → точка → поделиться → скопировать **код** (не ссылку) → HTML-блок. Статичная съёмка.
- Любой сторонний embed по тому же правилу: HTML-блок, размер боксом, проверка на ТВ — тяжёлые виджеты тормозят на слабых панелях.

## 13. Родные соцленты и RSS

Левая панель → «Социальные сети». Это родные элементы, не iframe, со стилем карточек в панели элемента и демо-данными до подключения источника:

- **ВКонтакте** — посты стены, фото альбома, вложения; требует подключённого сервиса ВК в настройках аккаунта (OAuth) и аккаунта с правами на группу.
- **Telegram** — посты публичного канала или чата.
- **Одноклассники** — посты группы.
- **RSS** — любой валидный URL RSS/Atom-ленты (`/feed` новостного сайта; `https://s.prtv.su/feed` — валидная лента для теста).

Работают только публичные источники. Картинки и аватары грузятся с сайтов-источников — заблокирован источник, пуста лента. Иконки Facebook, Instagram и Twitter/X в панели есть, рабочие элементы не подтверждены; не обещать.
